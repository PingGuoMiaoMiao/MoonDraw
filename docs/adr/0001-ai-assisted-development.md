# ADR 0001：AI 辅助开发的边界与可复核性

- 状态：已采纳
- 日期：2026-11-25

## 背景

本项目在实现过程中使用 AI 编程助手（具备文件读写、命令执行与测试运行能力的编码代理）。
赛事与评审会关注"AI 使用是否可解释"，因此需要记录清楚：AI 做了什么、人做了什么决定、
结论如何被验证。

## 决定

1. **AI 参与实现，但不裁定方向。** 产品方向、范围取舍、验收口径由人决定。例如：
   - 吸附优先级：先网格后对齐线，且**对齐线优先**（与主流设计工具一致），而不是"严格网格"；
   - Mermaid 导入**只取图不取样式**，丢弃 `classDef` / `style` / `click`；
   - 布局只做按深度分层，不引入完整 dagre 算法；
   - 交付形态优先"零依赖便携壳"，Tauri 作为增强路径。

2. **每条能力必须先有测试再接 UI。** 内核（`scene` / `geom` / `select` / `arrange` /
   `mermaid` / `layout` / `docs`）不引用 DOM，新增行为先写白盒单测（当前 51 项）。

3. **验收标准不由 AI 自评。** 以 `tools/verify.ps1`（类型检查 → 单测 → 构建 → 产物新鲜度
   → 端到端）的结果为准；当前 59 项端到端断言全部通过。

4. **不编造数据。** 无法测量的量显式标注"未验证"（例如 Canvas 帧时间——无头环境虚拟时钟
   不推进，测得恒为 0；中文输入法候选框只能用人工验收）。

## AI 引入的缺陷（均由自动化测试捕获，而非人工审查）

| 缺陷 | 发现方式 | 修复 |
|---|---|---|
| 删除选中图形时漏记快照，Delete 后无法撤销 | 端到端断言 D3 | 先 `snapshot()` 再删除 |
| Mermaid `\|标签\|` 的竖线被当作连接符，`B -->\|是\| C` 解析出节点 `是C` | 单测 + 端到端 G 组 | 重写分词器为「节点 / 连接符 / 标签」三段式 |
| 等间距分布先改坐标再记快照，撤销失效 | 端到端断言 O5 | 快照提到变更之前 |
| 视口导出按世界尺寸缩放，导出的不是"所见即所得" | 端到端断言 N2 | 视口单独走"相机同比例放大"分支 |
| 裸节点引用覆盖已定义标签（`B --> C` 把 `B{判断}` 刷成 `B`） | 新增 CLI 示例运行时发现 | 裸引用返回空文本，不再覆盖 |

## 后果

- 正面：实现速度快；缺陷暴露依赖测试而非审查，说明验证体系本身是有效的。
- 负面：AI 生成的代码风格与命名需要人工统一；文档与注释需要逐条核对口径。
- 约束：任何"已验证"的声明都必须能由仓库内脚本复现，否则降级为"未验证"。
